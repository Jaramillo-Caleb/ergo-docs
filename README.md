# Ergo

Aplicación de escritorio ligera que usa la cámara web estándar para analizar la postura del usuario en tiempo real mediante visión por computador y alertarlo cuando se encorva. Integra un temporizador de productividad (tipo Pomodoro) y pausas activas. El análisis se ejecuta de forma local, sin enviar video a servidores en la nube.

Este repositorio contiene la **documentación del proyecto**, organizada por etapas del ciclo del proyecto de inversión.

## Estado actual
